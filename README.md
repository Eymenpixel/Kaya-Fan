## 🛠️ How to Contribute (Pull Request Guide)

To add your own files, code snippets, or changes to this repository, follow these simple steps:

1. **Fork the Repo:** Click the **"Fork"** button in the top-right corner of this page to create a personal copy of this project under your GitHub account.
2. **Add Your Files:** Go to your newly forked repository. Click **"Add file"** > **"Upload files"** and drag your code or packages into the folder.
3. **Commit Changes:** Scroll down to the bottom of the page, write a quick summary of what you added, and click the green **"Commit changes"** button.
4. **Open a Pull Request:** Navigate back to the original repository (`Eymenpixel/Kaya`), go to the **"Pull requests"** tab, and click the green **"New pull request"** button.
5. **Submit:** Click **"Create pull request"** to send it over. I will review your submission and merge it into the main repository if it looks good!

Thank you for contributing to the Kaya package manager infrastructure! Keep it On! 🦖
